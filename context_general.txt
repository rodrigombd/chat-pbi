## TASA DE CONVERSIÓN (CR) — fórmula única
Para un curso o segmento dado:
- Numerador = contactos particulares (filas).
- Denominador = contactos particulares + leads (filas).

```python
fact = leads_contacts[leads_contacts["Curso"] == "2025/2026"]
contacts = len(fact[
    (fact["Tipo de registro"] == "Contacts") &
    (fact["Particular o Grupo"] == "Particular")
])
leads = len(fact[fact["Tipo de registro"] == "Leads"])
denom = contacts + leads
cr = contacts / denom if denom > 0 else 0.0
```

# MAPAS GEOGRÁFICOS INTERACTIVOS (PLOTLY MAPBOX)

Cuando el usuario pida un **mapa**, **mapa de calor geográfico**, **dónde se concentran**, **por zonas/ciudades en el mapa** o similar, genera un gráfico geográfico de Plotly con la misma estructura `"__plotly__": True`. El front ya tiene Plotly cargado y renderiza mapas sin necesidad de token (usa un estilo limpio y corporativo `"carto-positron"`; el front además embellece el mapa automáticamente con halos en las burbujas y centrado en España).
Si te piden un gráfico o mapa, debes asignar a la variable resultado un diccionario que obligatoriamente contenga la clave {"__plotly__": True, "data": [...], "layout": {...}}.

## Coordenadas disponibles (NO las inventes)
Tienes en el entorno una función global y un diccionario para ubicar ciudades españolas:
- `coords_ciudad("Madrid")` → devuelve la tupla `(lat, lon)` o `None` si no se conoce. Es **tolerante a tildes y mayúsculas** (`coords_ciudad("alcala de henares")` funciona).
- `CIUDADES_ES_COORDS` → dict `{"Madrid": (40.4168, -3.7038), ...}`.

REGLA: para situar una ciudad en el mapa usa SIEMPRE `coords_ciudad(...)`. NUNCA escribas coordenadas a mano. Si una ciudad devuelve `None`, EXCLÚYELA del mapa (no la inventes). Al final de este documento hay una lista de las ciudades con coordenadas conocidas.

## Qué tipo de mapa elegir
Decide según la pregunta:
- **Burbujas (`scattermapbox`)**: por defecto para volúmenes o tasas por ciudad. El tamaño del marcador codifica la magnitud y el color puede reforzarla. Es el más legible para comparar ciudades concretas.
- **Mapa de calor de densidad (`densitymapbox`)**: cuando el usuario pida explícitamente "mapa de calor", "zonas calientes" o "densidad". Pondera cada ciudad por su métrica con la clave `z`.
- Para volúmenes usa conteos de filas; para tasa de conversión usa la fórmula de CR ya definida, por ciudad.

## Patrón general (calcula primero un DataFrame con lat/lon)
Filtra y agrega por la columna de ciudad que corresponda a la pregunta (`Ciudad_deinteres_corregido` para ciudad de interés, `Ciudad_actual_corregido` para ciudad actual). Añade columnas `lat` y `lon` con `coords_ciudad`, elimina las ciudades sin coordenada, y adjunta el DataFrame en `"__data__"`.

## Reglas obligatorias para mapas
