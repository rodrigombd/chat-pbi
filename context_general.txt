## TASA DE CONVERSIÓN (CR) — fórmula única
Para un curso o segmento dado:
- Numerador = contactos particulares.
- Denominador = contactos particulares + leads.

```python
fact = leads_contacts[leads_contacts["Curso"] == "2025/2026"]
contacts = fact[
    (fact["Tipo de registro"] == "Contacts") &
    (fact["Particular o Grupo"] == "Particular")
]["Correo electrónico"].nunique()
leads = fact[fact["Tipo de registro"] == "Leads"]["Correo electrónico"].nunique()
denom = contacts + leads
cr = contacts / denom if denom > 0 else 0.0
```

NO inventes otra fórmula. Esta es la única válida.

## Variación entre dos periodos
- Variación absoluta de CR (en puntos porcentuales): `cr_nuevo - cr_viejo`.
- Variación porcentual de un volumen: `(v_nuevo / v_viejo) - 1` si `v_viejo > 0`.

## Selección del tipo de gráfico

- **Serie temporal** (evolución por fechas, meses o años) → `"type": "scatter", "mode": "lines+markers"`. Una línea por serie.
- **Comparación entre categorías** (top N, ranking) → `"type": "bar"`. Si hay más de 6 categorías, usa `"orientation": "h"` (horizontal) y ordena de mayor a menor (la mayor arriba). Si son ≤ 6, vertical.
- **Comparar dos métricas/periodos por categoría** → barras AGRUPADAS: dos traces de tipo `"bar"` con `"layout": {"barmode": "group"}`. Si quieres apilar, `"barmode": "stack"`. NUNCA dos tartas.
- **Composición/proporción** → barras apiladas al 100% (calcula las proporciones tú y pon ejes en `"tickformat": ".0%"`).
- **TARTA** (`"type": "pie"`): PROHIBIDA salvo que el usuario la pida EXPLÍCITAMENTE con la palabra "tarta", "pie" o "donut".

## Etiquetas y hover (obligatorios)

- En barras añade `"text"` y `"textposition": "auto"` para mostrar el valor sobre cada barra. Usa `"texttemplate": "%{y:,.0f}"` (o `:,.1%` para porcentajes).
- En líneas añade `"hovertemplate"` claro: `"<b>%{x}</b><br>%{y:,.0f}<extra></extra>"`.
- Para porcentajes, formatea con `:.1%` o pasa los valores ya como porcentaje y usa `:.1f` con sufijo `"%"`.
