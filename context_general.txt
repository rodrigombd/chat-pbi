## TASA DE CONVERSIÓN (CR) — fórmula única
Para un curso o segmento dado:
- Numerador = contactos particulares (filas).
- Denominador = contactos particulares + leads (filas).

```python
fact = leads_contacts[leads_contacts["Curso"] == "2025/2026"]
contacts = len(fact[
    (fact["Tipo de registro"] == "Contacts") &
    (fact["Particular o Grupo"] == "Particular")
])
leads = len(fact[fact["Tipo de registro"] == "Leads"])
denom = contacts + leads
cr = contacts / denom if denom > 0 else 0.0
```

NO inventes otra fórmula. Esta es la única válida.

> **Importante sobre el formato de CR**: la tasa de conversión SIEMPRE se expresa al usuario como porcentaje (`12,4 %`), nunca como fracción de 0 a 1. Si la devuelves en un escalar, formátéala con `f"{cr:.1%}"`. Si la devuelves en una tabla, multiplica por 100 y añade `" %"` o usa `.map(lambda x: f"{x:.1%}")`. Si la devuelves en un gráfico Plotly, usa `"tickformat": ".1%"` en el eje Y o pasa los valores ya como porcentajes con sufijo `"%"`.

## Variación entre dos periodos
- Variación absoluta de CR (en puntos porcentuales): `(cr_nuevo - cr_viejo) * 100`, expresada con sufijo `"pp"`.
- Variación porcentual de un volumen: `(v_nuevo / v_viejo) - 1` si `v_viejo > 0`, formateada como porcentaje con un decimal.

# MAPAS GEOGRÁFICOS INTERACTIVOS (PLOTLY MAPBOX)

Cuando el usuario pida un **mapa**, **mapa de calor geográfico**, **dónde se concentran**, **por zonas/ciudades en el mapa** o similar, genera un gráfico geográfico de Plotly con la misma estructura `"__plotly__": True`. El front ya tiene Plotly cargado y renderiza mapas sin necesidad de token (usa el estilo `"open-street-map"`).

## Coordenadas disponibles (NO las inventes)
Tienes en el entorno una función global y un diccionario para ubicar ciudades españolas:
- `coords_ciudad("Madrid")` → devuelve la tupla `(lat, lon)` o `None` si no se conoce. Es **tolerante a tildes y mayúsculas** (`coords_ciudad("alcala de henares")` funciona).
- `CIUDADES_ES_COORDS` → dict `{"Madrid": (40.4168, -3.7038), ...}`.

REGLA: para situar una ciudad en el mapa usa SIEMPRE `coords_ciudad(...)`. NUNCA escribas coordenadas a mano. Si una ciudad devuelve `None`, EXCLÚYELA del mapa (no la inventes). Al final de este documento hay una lista de las ciudades con coordenadas conocidas.

## Qué tipo de mapa elegir
Decide según la pregunta:
- **Burbujas (`scattermapbox`)**: por defecto para volúmenes o tasas por ciudad. El tamaño del marcador codifica la magnitud y el color puede reforzarla. Es el más legible para comparar ciudades concretas.
- **Mapa de calor de densidad (`densitymapbox`)**: cuando el usuario pida explícitamente "mapa de calor", "zonas calientes" o "densidad". Pondera cada ciudad por su métrica con la clave `z`.
- Para volúmenes usa conteos de filas; para tasa de conversión usa la fórmula de CR ya definida, por ciudad.

## Patrón general (calcula primero un DataFrame con lat/lon)
Filtra y agrega por la columna de ciudad que corresponda a la pregunta (`Ciudad_deinteres_corregido` para ciudad de interés, `Ciudad_actual_corregido` para ciudad actual). Añade columnas `lat` y `lon` con `coords_ciudad`, elimina las ciudades sin coordenada, y adjunta el DataFrame en `"__data__"`.

### Ejemplo A — Burbujas: volumen de leads por ciudad de interés
```python
df = (
    leads_contacts[leads_contacts["Tipo de registro"] == "Leads"]
    .groupby("Ciudad_deinteres_corregido")
    .size()
    .reset_index(name="Leads")
    .rename(columns={"Ciudad_deinteres_corregido": "Ciudad"})
)
df["coord"] = df["Ciudad"].apply(coords_ciudad)
df = df[df["coord"].notna()].copy()
df["lat"] = df["coord"].apply(lambda c: c[0])
df["lon"] = df["coord"].apply(lambda c: c[1])
df = df.drop(columns=["coord"]).sort_values("Leads", ascending=False)

# Tamaño de burbuja proporcional (escalado para que se vean todas)
max_leads = df["Leads"].max()
sizes = (df["Leads"] / max_leads * 45 + 8).tolist() if max_leads > 0 else [10] * len(df)

resultado = {
    "__plotly__": True,
    "data": [{
        "type": "scattermapbox",
        "lat": df["lat"].tolist(),
        "lon": df["lon"].tolist(),
        "text": [f"{c}: {v:,.0f} leads".replace(",", ".") for c, v in zip(df["Ciudad"], df["Leads"])],
        "hoverinfo": "text",
        "mode": "markers",
        "marker": {
            "size": sizes,
            "color": df["Leads"].tolist(),
            "colorscale": [[0, "#e8f8e0"], [1, "#4a9e2e"]],
            "showscale": True,
            "colorbar": {"title": "Leads"},
            "sizemode": "diameter",
        },
    }],
    "layout": {
        "title": {"text": "Leads por ciudad de interés", "x": 0.02, "xanchor": "left", "font": {"size": 16}},
        "mapbox": {"style": "open-street-map", "center": {"lat": 40.0, "lon": -3.7}, "zoom": 4.6},
        "margin": {"l": 0, "r": 0, "t": 50, "b": 0},
        "font": {"family": "Arial, Helvetica, sans-serif", "size": 12, "color": "#1a1a1a"},
    },
    "config": {"displaylogo": False, "responsive": True},
    "__data__": df[["Ciudad", "Leads", "lat", "lon"]],
```

## Reglas obligatorias para mapas
1. SIEMPRE `"mapbox": {"style": "open-street-map", ...}` en el layout (sin token).
2. Centra en España: `"center": {"lat": 40.0, "lon": -3.7}, "zoom": 4.6` salvo que el usuario acote una zona.
3. `"margin": {"l": 0, "r": 0, "t": 50, "b": 0}` para que el mapa ocupe el ancho.
4. Pasa `lat`/`lon`/`z` como **listas nativas** con `.tolist()` (igual que el resto de gráficos: nunca Series crudas).
5. Excluye ciudades sin coordenada (`coords_ciudad(...) is None`).
6. Adjunta el DataFrame en `"__data__"` con columnas `Ciudad`, la métrica, `lat`, `lon`.
7. Para tasa de conversión por ciudad, calcula la CR por ciudad con la fórmula oficial y usa esos valores como color/`z` (formatea como porcentaje en el hover).
