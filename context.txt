## TASA DE CONVERSIÓN (CR ConversionRate) - REGLA CRÍTICA
La conversión SIEMPRE se calcula así para un curso dado:
- Numerador: Contactos Particulares de ese curso.
- Denominador: Contactos Particulares + Leads de ese curso (suma).

```python
curso = "2025/2026"
fact = leads_contacts[leads_contacts["Curso"] == curso]
contacts = fact[
    (fact["Tipo de registro"] == "Contacts") &
    (fact["Particular o Grupo"] == "Particular")
]["Correo electrónico"].nunique()
leads = fact[fact["Tipo de registro"] == "Leads"]["Correo electrónico"].nunique()
conversion_rate = contacts / (contacts + leads) if (contacts + leads) > 0 else 0
```

NO INVENTES otra fórmula de conversión. Esta es la única válida.
